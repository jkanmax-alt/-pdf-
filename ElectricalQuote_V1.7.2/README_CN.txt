电气图纸智能识别 ElectricalQuote V1.7.2 修复版

核心流程：PDF分柜 → 元器件候选识别 → 人工核对数量与规格 → 导出清单 → 后续报价。

Windows 使用方法：
1. 将本包解压到新的英文路径，不要覆盖旧版本。
2. 安装 Python 3.11 或以上（包含 tkinter），进入 source，首次运行 install_windows.bat。
3. 安装 Tesseract OCR，确保 CMD 中 tesseract --version 可执行；程序也会查找常规安装路径 C:\Program Files\Tesseract-OCR。
4. 双击 start_windows.bat，打开 PDF，点击“检测整份PDF分柜”，核对边界后识别当前柜或全部柜。
5. 识别结果为候选。主进线三相计量的CT按一套3只（符号或用户规则），数量依据会注明；其他“待确认”数量保持空白；请依据原图修改数量与规格，再设为“已确认”。
6. 新增元器件会绑定当前选中的柜子。已人工确认、修改或标定的记录不会被重新OCR自动覆盖。
7. “分类汇总”和“识别质量”区分候选已知数量、已确认数量与数量未知记录。
8. Excel保留明细、分类汇总、防雷参数和规则预览，另有“已确认汇总”表。候选数不等于最终BOM数量。
9. 保存JSON项目后可继续核对。原PDF移动时，打开项目再点击“关联原PDF”，不会清除已有清单。

修复范围：
- 竖向RCBO漏识别、主开/短回路的+N丢失。
- 多组馈线只取最长组的问题，按每组行距OCR与定位，孤立线提示核对。
- CT依据三相测量结构按一套3只；符号实测与用户配置规则分开记录，人工确认值保留。
- 多组SPD/SCB缩为各1个的问题；按实际文字位置分实体，无法核实时保留原记录并告警。
- 人工补录隐藏、连续重识别覆盖人工数据、失效路径错绑旧PDF。
- 无方向证据时误转270度、两轮OCR重复文字框、多区域缓存归属错误。

校验：
- GitHub源码包不包含用户原始图纸与历史报价。实际PDF校验前，将原始包中的三份PDF在本地复制到本项目samples文件夹。
- 无原图时，可在source目录运行 python -m unittest discover -p "test_*fixes.py"，执行不需要样例图纸的针对性回归。
- 双击 verify_windows.bat：针对性回归与快速分柜校验。
- CMD中运行 verify_windows.bat --full：增加实际PDF OCR、四方向识别、14馈线样例验证。
- 不要使用 python -O 运行校验，因为历史样例校验使用assert。

说明：
- Excel生成改用openpyxl，按本版requirements重新安装依赖。
- 本版仍为Python项目包，不是独立EXE；build_exe_windows.bat为可选Windows打包入口。
- 当前自动流程重点支持断路器、隔离开关、VFD及部分测量和防雷器件。接触器、热继电器等仍需人工核查/补录。
- 复杂版式、模糊扫描图、中文标注仍可能漏识别。蓝框是文字证据，人工标定红框是器件位置，两者有区别。
- 新项目保存原PDF哈希用于身份核验；无哈希的旧项目只能验证页数/区域尺寸，重新关联时请人工确认原图。
- 当前修复在Linux Python后端和无界面UI回归中验证；Windows桌面启动与EXE打包需在Windows上验收。

本轮柜号/合框/CT/接触器/热继及负载选型修复，详见RELEASE_NOTES_V1.7.2.txt。GitHub源码不包含用户原始PDF与历史报价。
